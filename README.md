Um die Seite anzusehen, müssen alle Datein in einen Ordner heruntergeladen werden.
Die Seite kann dann durch öffnen von index.html gestartet werden.

Die Statistiken können sich unter https://docs.google.com/spreadsheets/d/1GjGhB_S6cC2IItTOOFI2fMfYYZxeP8p-U5fMrY6jrKQ/ angesehen werden.

**Verschiedene Modis** 

    Will man halbe Keks benutzen setzt man in der URL den Parameter: halbe-kekse. 

    Will man die Kekse einsammeln können setzt man in der URL den Parameter: kekse-sammeln. 
    
    Der Inhalt ist dabei egal

    Beispiel URL wenn beides gesetzt
    ...index.html?kekse-sammeln=1&halbe-kekse=1
